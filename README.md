# 活動平台

一個以校園與私人活動為核心的活動管理平台。使用者可以在活動大廳探索活動、加入活動、完成現場任務與問答挑戰；活動建立者則可以建立、管理及刪除自己的活動，讓線上資訊與實體參與流程連結在一起。

## 主要功能

### 活動大廳

- 瀏覽全部、校園、私人與已加入的活動
- 查看活動名稱、類別、主題標籤、日期、時間與參與人數
- 支援活動名稱跑馬燈公告，點擊後可直接前往對應活動
- 無實體地點的活動不顯示地點標籤
- 查看活動發布者；建立者可以選擇匿名發布
- 活動建立者可透過「我的活動」快速管理自己建立的活動

### 建立活動

- 設定活動類別、名稱、開始／結束日期與時間
- 支援跨日活動
- 設定實體地點，或勾選「無實體地點」
- 設定人數上限，或選擇無人數上限
- 建立最多五個主題標籤並自訂標籤顏色
- 建立多個任務，設定完成次數與任務積分
- 校園活動任務積分上限為 10 分
- 可選擇建立活動房間與圖像配對遊戲
- 圖像配對遊戲每次配對積分上限為 3 分
- 可建立獨立問答題，不依賴活動房間
- 問答題支援多選正確答案，每題積分上限為 5 分
- 建立表單提供即時合理性檢查，包括日期、時間、人數、重複名稱、重複任務、重複題目與重複選項
- 建立成功後顯示活動資訊與建立者專屬代碼確認視窗

### 活動參與與任務

- 同一位使用者在同一活動只能加入一次
- 加入活動後才會顯示活動房間代碼
- 任務需輸入活動建立者提供的專屬代碼才能完成，避免自行刷分
- 顯示任務完成次數與進度條
- 問答挑戰支援多選作答與答題結果提示
- 圖像配對遊戲提供水果名稱與圖片的互動配對玩法

### 我的生涯

- 顯示總積分
- 依參加時間顯示歷史活動
- 已完成與未完成活動使用不同視覺樣式
- 點擊活動紀錄可展開查看當時的時間與地點
- 歷史紀錄只提供資訊查看，不會重新進入任務房間

### 其他功能

- 社交頁面與好友互動
- 依目前活動功能設計的成就系統
- 帳戶、登入、註冊與密碼管理介面
- 語音助手與語音朗讀活動資訊
- 深色模式、高對比與文字大小設定

## 快速開始

### 安裝依賴

```bash
npm install
```

### 啟動開發伺服器

```bash
npm run dev
```

啟動後依終端機顯示的網址開啟應用程式，通常為 `http://localhost:8080/`。

### 建置正式版本

```bash
npm run build
```

### 預覽正式版本

```bash
npm run preview
```

### 執行測試與檢查

```bash
npm run test
npm run lint
```

## 技術架構

- **前端框架**：React 18
- **程式語言**：TypeScript
- **建置工具**：Vite
- **路由**：React Router
- **樣式系統**：Tailwind CSS
- **元件系統**：shadcn/ui、Radix UI
- **圖示**：Lucide React
- **通知提示**：Sonner
- **狀態管理**：React Context 與自訂 Hooks
- **圖表**：Recharts
- **測試工具**：Vitest、Testing Library

目前活動資料以前端 Hook 與記憶體狀態模擬，適合展示與功能原型驗證；若要投入正式環境，後續可接上後端 API、使用者驗證與資料庫持久化。

## 專案結構

```text
src/
├── components/       # 共用版面與 UI 元件
│   └── ui/           # Radix/shadcn UI 元件
├── contexts/         # 全域使用者與設定狀態
├── hooks/            # 活動資料與共用功能 Hooks
├── lib/              # 工具函式
├── pages/            # 活動大廳、建立活動、任務房間等頁面
└── test/             # 測試檔案
```

## 開發流程

1. 建立功能分支。
2. 安裝依賴並啟動開發伺服器。
3. 完成功能後執行 `npm run build`、`npm run lint` 與必要測試。
4. 提交變更並建立 Pull Request。
